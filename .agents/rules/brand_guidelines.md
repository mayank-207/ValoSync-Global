# VeloSync Global Brand Color Guidelines

Always strictly enforce the following official VeloSync Global brand color system across all UI elements, components, styles, and marketing surfaces:

- **Primary Blue**: `#0B3D91` — Dominant brand color for primary actions, active states, key headings.
- **Brand Blue**: `#1565C0` — Secondary technology highlights & subtle gradients.
- **Gold Accent**: `#D4AF37` — Selective premium accent for highlights, badges, icons, and key brand details.
- **Dark/Navy**: `#071A33` — Header navigation, footer, dark section hero backgrounds, dark card surfaces.
- **Dark Text**: `#1A1A1A` — Primary readable typography on light surfaces.
- **Card/Input Border**: `#D9E1EC` — Subtle neutral borders.
- **Main Canvas**: `#FFFFFF` / `#F7F9FC` — Default clean whitespace.
